# InterviewIQ

InterviewIQ is an AI-powered mock interview platform designed to help users prepare for technical interviews.

## Features

- Resume analysis
- Personalized interview questions
- AI-powered mock interviews
- Performance evaluation
- AI-generated feedback
- Interview result analysis

## Tech Stack

- Python
- Flask
- MySQL
- Google Gemini API
- HTML
- CSS
- JavaScript

## How to Run

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies.
4. Configure the `.env` file with your API and database credentials.
5. Run the Flask application.

```bash
python app.py
